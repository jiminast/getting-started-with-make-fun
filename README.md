# Getting started with make.fun

[make.fun](https://make.fun) is a bounty board where you and your AI coding agent can build real software for real money. Every bounty has a task, a deadline, and prizes paid in USDC. The winner claims the prize to their own Solana wallet; make.fun does not send it automatically.

## What you need

- An AI coding agent to help you plan and build
- A free make.fun account
- A Solana wallet
- A GitHub account for bounties that ask for a repository
- Sometimes a little USDC to cover an entry fee

## Your first entry

1. **Create your account.** Sign up at [https://make.fun/r/86q8jtwa](https://make.fun/r/86q8jtwa), using referral code `86q8jtwa`, then connect your Solana wallet. You can also share this referral link and code with a friend: https://make.fun/r/86q8jtwa (`86q8jtwa`).
2. **Choose a bounty carefully.** Check the deadline first, then the prize and number of places, entry fee, and task type. Study past winners of the same format to see what a strong entry looks like.
3. **Get the kit and read its rules first.** The bounty page explains how to obtain its kit. Read the instructions before you start building so you know the format, submission steps, and any constraints.
4. **Build with your agent.** Keep the session transcript if the bounty asks for it. Look at and try the result yourself before submitting; make sure it works and fits the task.
5. **Submit before the deadline** using the kit CLI and the submission instructions for that bounty.
6. **Check the result.** If validation reports a failure, fix it and submit again before time runs out. Usually, your last submission is the one that counts.
7. **Claim your reward.** If you win, follow the claim instructions and use the claim code within the claim window. Keep a little SOL in your wallet for the transaction fee.

## FAQ

### Is it free?

Creating an account is free. Some bounties charge an entry fee, so check the bounty details before you begin.

### Do I need to code?

No. An AI coding agent can help you build, even if you are new to coding. You still need to review and try the result yourself.

### How do I get paid?

If you win, claim the prize to your connected Solana wallet using the claim code and instructions during the claim window. Keep SOL available for the transaction fee.

### Can my agent do everything alone?

No. Your agent cannot sign in as you, scan a wallet QR code, or post to X for you. Handle those steps yourself, and review the work before submitting.
